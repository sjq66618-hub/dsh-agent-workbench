# IM 远程控制凭据准备指南（QQ / 微信 / 企业微信）

> 目标：拿到能用的 QQ Bot 与微信侧通道，之后在隔离 profile 里试驾。
> 原则：**不要把 AppSecret、二维码、cookie 发到聊天里**；只记录「已填好/已扫码」的状态。

## 0. 安全前提

- 用**专用账号**（QQ 小号 / 专用微信 / 企业微信），不用主号。
- 只开**私聊**，不开群聊；开白名单；限频。
- Secret 只填进 DSH 设置页或凭据库，不贴到对话、不写进代码。
- 试驾跑在 `imtest` 复制 profile，通过后再进 desktop。

## 1. QQ 官方 Bot（推荐先做）

入口：

- QQ 开放平台：<https://q.qq.com/>
- 官方文档：<https://bot.q.qq.com/wiki/>

步骤（以页面当前文案为准）：

1. 注册/登录 QQ 开放平台，选择个人或企业开发者资质。
2. 创建机器人：填名称、头像、简介、使用场景/类目。
3. 进入「开发设置」，拿 **AppID** 和 **AppSecret**（Secret 通常只显示一次，丢了要重置）。
4. 在「功能配置」里开启**单聊 / C2C 私聊**权限；确认机器人可被添加为好友。
5. 配置**沙箱环境**，把测试 QQ 号加入沙箱测试成员。
6. 用测试 QQ 私聊机器人，发 `/help` 或“你好”，确认有回复。
7. 提交审核；审核通过前只在沙箱可用。

常见坑：

- 机器人没加好友 / 没开 C2C，私聊无响应。
- 沙箱测试成员没加，消息被丢弃。
- 类目/资质与用途不符，审核被拒。
- Secret 泄露：立即在后台重置。

验收：沙箱内私聊机器人，能收到一条文字回复。

## 2. 微信 iLink（先确认能不能开通）

`@michengai/dsh-im-connect` 的微信通道是 **官方 iLink 扫码**，不是逆向个人微信协议。但目前公开的 iLink 开通入口不明确（`ilink.qq.com` 当前无法访问），需要你先确认资格。

确认清单（任何一项为“否”就不要走 iLink）：

1. 你是否能拿到 iLink 服务方/租户资格？
2. 是否提供**专用微信号**和扫码入口？
3. 是否支持私聊的文本、图片、文件（语音可选）？
4. 是否有审核、月费、调用限制？
5. 扫码后能否稳定在线，不被踢下线？

如果拿不到：**直接走企业微信 Bot**，不要碰个人微信 hook。

## 3. 企业微信 Bot（备选，推荐先跑通）

入口：<https://work.weixin.qq.com/>

步骤：

1. 注册企业微信（个人可以注册小团队/空壳企业）。
2. 管理后台 → 应用管理 → 创建自建应用或智能机器人。
3. 拿 **CorpID / AgentID / Secret**，或智能机器人的 **Bot ID / Secret**。
4. 配置可见范围（只勾自己）、可信 IP（如后台要求）。
5. 在 im-connect 设置里选 WeCom，扫码或填凭据。
6. 企业微信里私聊机器人，发 `/help` 验证。

验收：企微私聊机器人有回复，且只有你的账号能触发。

## 4. 在 DSH 里怎么填

1. 安装 `@michengai/dsh-im-connect`（先 `imtest` profile，不进主环境）。
2. 打开 **设置 → IM Assistant**（或插件对应设置页）。
3. QQ：填 AppID / AppSecret；微信/企微：扫码。
4. 每个账号单独设：工作区、模型、权限、私聊准入、发送模式。
5. 先发 `/help`，再发“列出工作区”，确认链路。

## 5. 我这边需要你反馈什么

只反馈状态，不发凭据：

- [ ] QQ Bot：AppID/Secret 已填入 DSH；测试 QQ 号已加机器人；沙箱私聊有回复。
- [ ] 微信：iLink 能否开通（能/不能/待确认）。
- [ ] 企业微信：是否已建 Bot 并扫码。
- [ ] 你希望 IM 会话默认用哪个工作区 / 哪个 preset（默认 `wb-main`）。
- [ ] 是否允许我在 `imtest` profile 里装插件并重启测试。

3. IM 稳定后，再开 QQ 音乐、百度网盘插件（本轮只出 plan，不写代码）。
