## 五、MCP 服务器（真正能扩能力的一层）

DSH 通过 `@deepseek-ai/dsh-mcp-client` 接任何 MCP 服务器，两种传输：`stdio`（本地命令）和 `streamable-http`（远端 URL）。

### 5.1 当前环境已接 5 个（在 `workbench/cordis.patch.yml` 里）

| 服务器 | 传输 | 命令/地址 |
|---|---|---|
| `context7` | stdio | `npx -y @upstash/context7-mcp@latest` |
| `deepwiki` | streamable-http | `https://mcp.deepwiki.com/mcp` |
| `playwright` | stdio | `npx -y @playwright/mcp@latest --headless` |
| `qqmusic` | stdio | `npx -y @sansenjian/qq-music-api-mcp@2.6.0` |
| `codex` | stdio | `node ./codex-bridge/mcp-codex-server.mjs` |

### 5.2 再接一个的写法

在 `~/.dsh/profiles/desktop/cordis.patch.yml` 追加：

```yaml
- insert:
    - id: mcp-你的名字
      name: '@deepseek-ai/dsh-mcp-client'
      config:
        serverName: 你的名字          # 工具前缀会变成 mcp__你的名字__*
        transport: stdio              # 或 streamable-http + url
        command: cmd
        args: ['/c', 'npx', '-y', '某个-mcp-server']
        toolCallTimeoutMs: 60000
```

重启后工具列表里出现 `mcp__<名字>__*`。

### 5.3 MCP 服务器去哪找

- 官方参考实现：[modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers)（filesystem / git / fetch / memory / sequential-thinking / time…）
- 社区总目录：[punkpeye/awesome-mcp-servers](https://github.com/punkpeye/awesome-mcp-servers)（数千个，按领域分）
- 也可以自己写：一个 stdio 进程 + JSON-RPC 就行，`codex-bridge/` 就是现成模板

**注意**：MCP 服务器不是 DSH 插件，是通用协议；接进来前看清楚它的权限范围（很多能读写文件、执行命令）。
