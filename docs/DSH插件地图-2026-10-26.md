## 1. 三条安装路径

**A. 命令行（最稳）**

```powershell
dsh plugin --profile desktop add dshmarket
```

`desktop` 是桌面客户端 profile；Web 端把 `profile` 换成 `web`。

**B. 界面「插件 → 发现」**

设置 → 插件 → 发现 → 索引源，添加：

```
https://cdn.jsdelivr.net/npm/dsh-plugin-catalog/index.json
```

这是官方格式 1 索引（和上面 3540 条同源），加进去后能搜索、能一键装。GitHub Pages 的两个镜像（`awesome-dsh-plugin.com/index.json`、`dshmarket.com/index.json`）在国内网络可能超过 15 秒超时，优先用 jsdelivr 那个。

**C. 装 `dshmarket`（推荐，一次到位）**

`dshmarket` 是应用内插件市场（v1.70.2）：设置页内浏览、搜索、分类筛选、一键安装/升级/停用，还带主题切换和配置备份。装完就不用再敲命令。

同类可选：`dsh-m`（4,000+ 目录 + 8 个 agent 工具）、`dsh-pick`（说需求给你按指标挑）、`dsh-plugin-upgrader`（批量升级/回滚）。

**卸载 / 停用**：`dsh-pick` 管的是一次性；日常用 `dsh-unplug`（列出所有加载层，完整卸载或临时禁用，默认只读，破坏性操作二次确认）。

## 7. 装之前的注意事项

1. **插件是第三方代码，跑在你的权限下。** 官方文档明说：工具审批不会沙箱化插件代码，它能读文件、用凭据、连网。上清单 ≠ 安全审查。装不熟的东西之前，先看源码，别在有 key 的环境里试。
2. **注意引擎约束。** 很多新插件要求 `>=0.2.1-rc.2` 甚至 `rc.3`。你现在是 `rc.2`，装之前看清单里的「引擎」列，或先升级（升级卡住的问题上一次已经定位为「后端优雅停止不退」）。
3. **一次装一个，装完重启。** 插件冲突是最常见的启动失败原因，`dsh-plugin-ops-bundle` 能在启动前体检、启动失败后归因。
4. **当前环境插件优先级**：`~/.dsh/profiles/desktop/cordis.patch.yml` 是你的补丁层，会覆盖 bundle 默认值；改之前先备份。
5. **索引源别乱加。** 只加 `cdn.jsdelivr.net/npm/dsh-plugin-catalog/index.json` 这一个够了，多个源会有重复条目和版本打架。
